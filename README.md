# Music-Playlist-Manager
DSA CCE-2: Music Playlist Manager using Doubly Linked List in C++

## Project Overview
This project implements a Music Playlist Manager using a Doubly Linked List in C++.

## Objectives
- Add and delete songs.
- Display the playlist in forward and reverse order.
- Play the current, next, and previous songs.
- Play the complete playlist and repeat all songs.

## Data Structure
Doubly Linked List

Each node stores song information and has `prev` and `next` pointers.

## Technology Used
- C++
- Visual Studio Code
- GitHub

## How to Run
1. Open the source file in Visual Studio Code.
2. Compile the C++ program using a C++ compiler.
3. Run the program and follow the menu options.
